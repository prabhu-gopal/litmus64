# Metamorphic relation catalogue

> **Status: draft.** Tier 0 (T0). Normative per RFC 2119.
> A relation here is a reviewable spec object, not a hidden heuristic (M10).

Each entry: the relation, its selection predicate over AST shape and type signature, its input
generator, and the honesty clause — a held relation proves non-equivalence was not found over N
inputs, NEVER that the function is equivalent.
